I build systems where machine learning has to be **trustworthy at the edge**: federated learning on IoT hardware, cryptographic guarantees on model aggregation, and fail-closed decision support for safety-critical settings.

- 🔥 Working on **multimodal fire detection** with federated learning on Raspberry Pi 5
- 🔐 Exploring **verifiable aggregation** and **post-quantum PKI** for federated learning
- ⛓️ Building **parametric insurance** on EVM chains with oracle commit-reveal
- 🏆 Runner-up, **Caterpillar Hackathon 2026 (VIT)** with ShiftMate

### 🚀 Featured projects

| Project | What it does | Stack |
|---|---|---|
| [**Multimodal Federated Fire Detection**](https://github.com/mkx12295-del/Multimodal-Federated-Fire-Detection-System) | Federated-learning fire node on Raspberry Pi 5. A local LLM fuses YOLO vision with BME680 sensor data; PWM buzzer, relay control, and XGBoost analysis, all on-device so data stays private. | Python · YOLO · XGBoost · LLM · RPi 5 |
| [**VERA-PQ**](https://github.com/mkx12295-del/vera-pq) | Forces IoT edge gateways to prove they actually ran a robust aggregation rule (coordinate-wise trimmed mean) instead of a plain average that poisoned devices can exploit. | Python · FL · Post-quantum crypto |
| [**PhysiTrust-FL**](https://github.com/mkx12295-del/physitrust_sim) | Web3 public key infrastructure for smart-grid devices that jointly train a federated anomaly detector, going beyond "who sent this update" to physical trust. | Python · Web3 · PKI · FL |
| [**Sentinel Flood Evacuation**](https://github.com/mkx12295-del/sentinel-flood-evacuation) | Certified, fail-closed dispatch gate for flood-evacuation decision support on the Fort Kochi road network, with a pre-registered evaluation. | Python · Graphs · Safety-critical ML |
| [**TIES**](https://github.com/mkx12295-del/TIES) | Parametric flight-delay and rainfall insurance: Solidity contracts, commit-reveal oracle nodes, interval settlement, and a React front end. | Solidity · TypeScript · React |
| [**ShiftMate**](https://github.com/mkx12295-del/Shiftmate) | In-cab companion for heavy-machine operators. 🥈 Runner-up, Caterpillar Hackathon 2026 (VIT). | Python |
